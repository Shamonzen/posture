fail AD-KRB-003 No computer other than a DC is trusted for unconstrained delegation posture-dc.posture.test

A host trusted for unconstrained delegation receives the TGT of everyone who authenticates to it. Whoever controls that host can reuse those tickets as the users, and can coerce a DC into authenticating to it, which yields the DC's own ticket and with it the domain.

ATT&CK
T1558 T1550.003

Evidence

ws01$

Remediation

Remove "Trust this computer for delegation to any service" from each listed computer; if a service really needs delegation, use constrained or resource-based constrained delegation to the named services only.

Set-ADAccountControl -Identity '<name>' -TrustedForDelegation $false
  • https://learn.microsoft.com/en-us/defender-for-identity/security-assessment-unconstrained-kerberos
fail AD-PWD-003 Passwords are not stored with reversible encryption posture-dc.posture.test

With reversible encryption the DC keeps every password it is given in a form it can turn back into cleartext, so anyone who can replicate from it (DCSync) or read its database gets the passwords themselves, not just hashes.

CIS
CIS Microsoft Windows Server 2019 Benchmark v4.0.0, control 1.1.6
ATT&CK
T1003.006

Evidence

{
  "fact": "domain.reversible_encryption",
  "value": true
}

Remediation

Disable "Store passwords using reversible encryption" in the Default Domain Policy, then have users change their passwords: the setting only stops new cleartext being stored.

fail AD-KRB-001 No enabled user account has a service principal name posture-dc.posture.test

Any domain user can ask for a service ticket for any SPN, and part of that ticket is encrypted with the service account's password hash. On a user account that password was chosen by a person, so it can be cracked offline at leisure (Kerberoasting).

ATT&CK
T1558.003

Evidence

svc-sql

Remediation

Move each listed service to a group managed service account (gMSA), whose 120-character password AD rotates itself. Until then, give the account a long random password and allow only AES (`Set-ADUser <name> -KerberosEncryptionType AES128,AES256`).

  • https://attack.mitre.org/techniques/T1558/003/
