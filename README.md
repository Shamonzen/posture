# Posture

Read-only security posture auditor for Linux (Ubuntu / Rocky), Windows Server + Active Directory, and Azure / Entra ID. Each finding is mapped to a CIS benchmark control and to the MITRE ATT&CK techniques the misconfiguration enables, with a suggested fix. Reports as JSON, HTML and SARIF.

**Work in progress.** See [`docs/PLAN.md`](docs/PLAN.md) for the plan and milestones.
